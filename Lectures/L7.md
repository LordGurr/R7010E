## Potential fields

Add obstacles as negative magnets that repel when close

The target works as a positive which attracts everywhere but gets weaker when close

## Bug

Bug 0
- If you hit an obstacle follow the wall until you have a free line towards goal

Bug 1
- If you hit an obstacle follow it fully around and then leave it whenever

Bug 2 Improved
- If you hit an obstacle follow it around until you intersect with the straight line from start to goal. Then leave the wall if possible
